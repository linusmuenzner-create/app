## Empfehlungen

- **Format:** MP4 (H.264) für maximale Browser-Kompatibilität
- **Auflösung:** 1080p (1920×1080) empfohlen
- **Bitrate:** ca. 5–8 Mbps für gute Qualität bei akzeptabler Ladezeit
- **Audio:** AAC, 128 kbps Stereo

Sobald du eine Datei hier ablegst, wird sie automatisch beim Klick auf die entsprechende Episode abgespielt.
