# Vorschaubilder (Thumbnails)

Lege deine Vorschaubilder hier ab. Wenn eine Datei fehlt, zeigt die App automatisch ein farbiges Platzhalter-Bild an.

## Erwartete Dateien

- `ep01.jpg` bis `ep18.jpg` – siehe `/data/episodes.json` für die Zuordnung

## Empfehlungen

- **Format:** JPG oder WebP
- **Seitenverhältnis:** 16:9 (z.B. 1280×720 px)
- **Größe:** ca. 200–400 KB pro Bild
- **Motiv:** Ein aussagekräftiges Foto aus der jeweiligen Episode
